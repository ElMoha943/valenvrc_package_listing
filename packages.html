How to Add This Listing to Your VCC

To add this listing to the VRChat Creator Companion:

  1. Open your VCC and go to Settings.
  2. Open the Packages tab and select Add Repository.
  3. Paste the URL displayed above and click Add.
  4. Review the repository info and click I Understand.
  5. Open a project to see the packages from this listing.
